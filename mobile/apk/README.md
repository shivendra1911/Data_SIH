### 🚀 How to Install on Your Android Phone:
1. Tap the download link above on your phone's browser.
2. If prompted with *"File might be harmful"* (standard Android warning for direct APK installs outside Play Store), tap **"Download Anyway"**.
3. Once downloaded, open the file and tap **"Install"**. (If asked to *"Allow from this source"*, toggle it on in Settings).
4. Open **NeerNetra**.
5. Grant the two essential permissions:
   * **Location Permission** (Set to *"While using the app"* or *"Allow all the time"*) — Required for GPS disaster coordinates.
   * **Bluetooth / Nearby Devices Permission** — Required for the offline peer-to-peer mesh when towers fail.
